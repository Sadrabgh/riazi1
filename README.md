# درسنامه جامع و مرحله‌به‌مرحله ریاضی عمومی ۱ (نسخه ۵)

وب‌سایت **کاملاً استاتیک** و موبایل‌محور برای آموزش ریاضی عمومی ۱ بر اساس جزوه **مهندس ابراهیم شاه‌ابراهیمی** (دانشگاه صنعتی خواجه نصیرالدین طوسی).

## ویژگی‌های نسخه ۵
- **پوشش کامل هر ۷ فصل جزوه (۸۳ صفحه علمی):** درسنامه دقیق و بدون حاشیه‌گویی در قالب گام‌های کوتاه + تمام مثال‌ها و تمام تمرین‌های جزوه با **راهنما، راه‌حل گام‌به‌گام و پاسخ نهایی**.
- **بازگردانی تسلط به صفر (Reset) در ۳ سطح:** امکان ریست تسلط برای یک گام مشخص، یک فصل کامل یا کل اطلاعات سایت با تأیید دو مرحله‌ای.
- **رسپانسیو و موبایل‌محور:** نوار ناوبری ثابت پایین صفحه در موبایل، کشوی فهرست گام‌ها، اسکرول ایمن فرمول‌های KaTeX بدون سرریز افقی صفحه، و تم روشن/تاریک با کنتراست بالا.
- **سبک و بدون امکانات زائد:** شامل برگه خلاصه فرمول‌ها (`#/cheatsheet`)، جستجوی سریع (`Ctrl+K`)، آرت‌ورک‌های انیمیشنی ۷ فصل و فونت محلی IRANYekan.

## اجرا و تست محلی

```bash
npm install
npm run dev
npm test
npm run build
```
